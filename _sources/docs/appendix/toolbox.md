<br><br>
<p style="color: red;"><strong>【途中】今後アップデート予定です</strong></p>

* まずは、研究したいテーマの仮説や理論的背景をしっかりと検討しましょう。
* 先行研究を読み、どのようなデータを用いているかを確認するのも良いでしょう。用いるデータの利点・限界なども記載されているはずです。
* 特に最近は研究の再現性等の観点からデータ（とコード）の公開が必須もしくは推奨されている論文誌が増えています。
    * データにフォーカスした論文誌も有ります

リサーチデータを探すためのリンク集

* e-Stat：日本の政府統計ポータルサイト (https://www.e-stat.go.jp/)
* World Bank Data (https://data.worldbank.org/)
* 東京大学社会科学研究所附属社会調査・データアーカイブ研究センター (https://csrda.iss.u-tokyo.ac.jp/)
* JoRAS (東京大学空間情報科学研究センター) (https://joras.csis.u-tokyo.ac.jp/)
* AEA (American Economic Association) Data and Code Repository (https://www.openicpsr.org/openicpsr/search/studies)
* Stanford Large Network Dataset Collection (https://snap.stanford.edu/data/)
* Sources of Data：練習などで使いやすい様々なデータが分野ごとの一覧になったリスト (https://stat2labs.sites.grinnell.edu/DataResources.html)
* Google Dataset Search (https://datasetsearch.research.google.com/)
